# Financial workflow-v1 fixture preparation

This version prepares W8-T1/T2 inputs only: 12 Market and 30 Portfolio synthetic cases. It does not execute a workflow, benchmark, provider, or model-quality comparison, and does not release W6/W7/W8 gates. Baseline is c4c44a0. The reviewed preparation matrix is the coordinator-supplied `logs/financial-mas/w8-evaluation-preparation.md` (2026-10-09).

`eval/financial_fixtures.py` verifies file hashes, loads typed requests and dependency records, and constructs typed tool inputs. `load_cases()` returns MarketCase/PortfolioCase lists. `market_dependencies()` returns accepted fixture backend dependencies; portfolio snapshot records are supplied to the accepted readonly snapshot loader by callers. No driver, dispatcher, persistence, holdings endpoint, or runtime calls occur in this loader. All 30 requests, snapshot records, histories, AllocationInput and CandidateInput adapters construct successfully. Negative P03 remains an AllocationInput with a failed deterministic check; SimulationInput rejects negative weights and must only be constructed after a passing check.

`workflow_v1/manifest.json` binds the two original source file hashes and new data hashes. Each row preserves original case identity, canonical source-case SHA256, effective request and original tool input/gold (Portfolio), plus an adapter SHA256. New rows have no original source-file identity; their adapter hash binds the new synthetic input. Event text has independent SHA256; typed EventRecord supplies validated evidence IDs. `build_corpus.py` reproducibly regenerates the new files without editing originals.

Market rows M01–M10 map the original ten cases in order. M07 denial_only preserves source contradiction: one denial is not a paired conflict. M08 no_events stays partial because numeric history exists. M10 weekday_notice retains the original Thursday text/date and is not weekend coverage. M11 adds a real Saturday September 26 notice. Future September 30 bars and events and unknown publication/late availability are excluded; observed_at is retrieval audit information. Every causal verification gold is false.
